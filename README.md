# Скилы для разработки в 1C:EDT по стандартам 1С

17 скилов для агента, который пишет код конфигурации в формате 1C:EDT. Основаны на стандартах раздела ИТС «Система стандартов и методик разработки конфигураций для платформы 1С:Предприятие 8», платформа 8.3.

Это не выгрузка статей и не замена подписки ИТС. В каждом скиле чеклист: что соблюдать в коде, на что смотреть при ревью, и номера статей, чтобы открыть первоисточник у себя на ИТС.

Формат обычный: папка и файл `SKILL.md`. Подойдёт Cursor, Claude Code и любому другому агенту, который читает такие скилы.

## Состав

1. Оформление модулей. Текст модуля, структура, имена, комментарии, параметр Отказ.
2. Конструкции языка. Выражения, клиент и сервер, типы, журнал регистрации, исключения.
3. Тексты запросов. Вёрстка, объединения, соединения, сортировка, ПОДОБНО.
4. Оптимизация запросов. Индексы, виртуальные таблицы, остатки, временные таблицы.
5. Транзакции и блокировки. Управляемые блокировки, запись регистров, контроль остатков.
6. Клиент-сервер. Где выполняется код, кэш, файлы, память, таймауты.
7. Безопасность кода. Серверный API, пароли, внешний код, запуск программ.
8. Права доступа. Роли, RLS, привилегированный режим, параметры сеанса.
9. Интерфейс 8.3. Командный интерфейс и компоновка формы под 1280×768.
10. Прикладные объекты. Модули объекта и менеджера, коллекции, проведение, СКД.
11. Метаданные. Имена и синонимы, общие модули, типы, реквизиты, функциональные опции.
12. Обработчики объектов. Запись, удаление, копирование, предопределённые, проведение.
13. Локализация. Строки, форматы, макеты, денежные поля.
14. Библиотеки. Поставка библиотеки, переопределяемые модули, обновление информационной базы.
15. Обмен данными. Планы обмена, регистрация, классификаторы, EnterpriseData.
16. Задания, подсистемы, время. Регламентные задания, подсистемы, часовые пояса.
17. Разработка интерфейсов. Формы, модальность, динамические списки, длительные операции, печать.

## Как установить

Скопируйте папки в каталог скилов агента.

- Cursor, Windows: `C:\Users\<имя>\.cursor\skills\`
- Cursor, macOS и Linux: `~/.cursor/skills/`
- Claude Code: `~/.claude/skills/`

Для одного проекта положите папки в `.cursor/skills/` или `.claude/skills/` этого проекта. В Cursor не кладите их в `skills-cursor`.

Откройте новый чат. Агент подключает скил сам, когда задача совпадает с его описанием. Чтобы проверить готовый модуль, напишите, по какому разделу смотреть.

Скилы рассчитаны на файлы EDT: `*.bsl` и `*.mdo` в `src`. Выгрузка конфигуратора с `Ext` и `ConfigDumpInfo.xml` для них не тот формат.
